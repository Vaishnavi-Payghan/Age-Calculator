# 🎂 Age Calculator

A simple Age Calculator web application that calculates a user's age based on their date of birth. Built using HTML, CSS, and JavaScript.

[Click Here to View Live Demo](https://vaishnavi-payghan.github.io/Age-Calculator/)

## ✨ Features

* Calculate age instantly
* Displays age in years
* Simple and user-friendly interface
* Responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
